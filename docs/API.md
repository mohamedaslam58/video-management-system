# API Reference (summary)

Full interactive docs (with request/response schemas) are auto-generated by
Swagger at **`GET /api/docs`** on the running backend, and the raw OpenAPI
JSON at **`GET /api/docs-json`**. This file is a quick-scan index.

All endpoints below are prefixed with `/api`. All except `auth/login` and
`auth/refresh` require `Authorization: Bearer <accessToken>`.

## Auth

| Method | Path | Roles | Description |
|---|---|---|---|
| POST | `/auth/login` | — | Email/password login → `{ accessToken, refreshToken, user }` |
| POST | `/auth/refresh` | — | Exchange refresh token for a new pair (rotates old one) |
| POST | `/auth/logout` | any | Revoke a refresh token |

## Users (admin only)

| Method | Path | Description |
|---|---|---|
| GET | `/users` | List all users |
| POST | `/users` | Create a user (email, fullName, password, role, cameraGroupIds?) |
| PATCH | `/users/:id` | Update role/status/camera-group scoping |
| DELETE | `/users/:id` | Remove a user |

## Cameras

| Method | Path | Roles | Description |
|---|---|---|---|
| GET | `/cameras` | admin/operator/viewer | List cameras (scoped to assigned groups for non-admins) |
| GET | `/cameras/:id` | admin/operator/viewer | Get one camera |
| POST | `/cameras` | admin | Register a camera (RTSP URL + optional credentials/ONVIF) |
| PATCH | `/cameras/:id` | admin | Update config, enable/disable |
| DELETE | `/cameras/:id` | admin | Remove a camera |
| GET | `/cameras/groups` | admin/operator/viewer | List camera groups |
| POST | `/cameras/groups` | admin | Create a camera group |

## Streaming

| Method | Path | Description |
|---|---|---|
| GET | `/streaming/:cameraId/live` | Resolve live HLS/WebRTC URLs + current online status |

## Recordings

| Method | Path | Description |
|---|---|---|
| GET | `/recordings/:cameraId/playback?from=&to=` | List recorded segments overlapping a time range, each with a short-lived signed playback URL |

## Events

| Method | Path | Roles | Description |
|---|---|---|---|
| POST | `/events/ingest` | admin/operator | Record a new event (motion, tamper, camera_offline/online, disk_full, manual_bookmark) and broadcast it over WebSocket |
| GET | `/events?cameraId=&limit=` | admin/operator/viewer | List recent events |
| PATCH | `/events/:id/acknowledge` | admin/operator | Mark an event acknowledged |

Live events also stream over WebSocket at the `/events` namespace
(`socket.io`, `?token=<accessToken>`), emitting an `event` message per new event.

## Search

| Method | Path | Description |
|---|---|---|
| GET | `/search?kind=events\|recordings&cameraId=&groupId=&eventType=&severity=&from=&to=&unacknowledgedOnly=` | Cross-entity search over events or recording segments |

## Health

| Method | Path | Description |
|---|---|---|
| GET | `/health` | Liveness check |
